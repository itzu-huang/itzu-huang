# ITZU_HUANG

個人學習與作品集，整理大學期間完成的課堂作業、專題、Side Projects、競賽成果，以及解題與技術筆記。

## 作品分類

### 1. 課堂獨立／專題實作

以產品化方式介紹規模較大的課程專題或畢業專題：

- **產品名稱**：一句話說明解決的問題
- **我的貢獻**：負責的功能、API、資料庫或協作內容
- **技術棧**：使用的語言、框架、資料庫與部署工具
- **成果**：Demo、截圖、簡報、影片或專案連結

### 2. 解決生活痛點的小工具

記錄自主發現問題、設計解法並完成實作的 Side Projects：

- **痛點**：原本遇到什麼不便
- **解法**：如何用程式改善流程
- **技術棧**：使用的技術
- **成果與反思**：實際效果、限制與後續規劃

### 3. 競賽、黑客松與研究成果

整理參與競賽、黑客松或大專生研究計畫的成果：

- 活動名稱與日期
- 團隊與個人負責內容
- 得獎、入圍或參賽成果
- 短時間原型開發的設計與取捨

### 4. 解題紀錄與學習筆記

整理 LeetCode、演算法練習與技術學習內容：

- 題目分類與解法
- 複雜度分析
- 常見錯誤與重點整理
- 延伸閱讀與實作連結

## Repository 結構

```text
.
├── projects/       # 課堂專題、畢業專題與完整作品
├── side-projects/  # 解決生活痛點的小工具
├── hackathons/     # 競賽、黑客松與研究成果
├── algorithms/     # LeetCode 與解題紀錄
└── notes/          # 技術筆記與學習整理
```
