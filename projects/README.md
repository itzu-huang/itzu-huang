## Diabetes Deterioration Risk Project

團隊專題：結合臨床摘要與連續血糖監測（CGM）資料，探索糖尿病併發症關聯風險分層、血糖動態與餘生醫療成本情境模擬。包含 Logistic Regression、XGBoost、Markov 模型、LSTM 與 Monte Carlo 模擬，並提供瀏覽器研究示範 App。

輔仁統計資訊學系115年第26屆學生專題成果發表會第六組

- [專題介紹與程式](https://github.com/itzu-huang/Diabetes_Deterioration_Risk_Project)
- [線上研究示範 App](https://itzu-huang.github.io/Diabetes_Deterioration_Risk_Project/)

研究與課程用途；併發症分類反映資料中的關聯，醫療成本為假設情境，不能作為診斷或治療依據。
